# arias-tale-rag

the arias-tale-rag repository is a monorepo with several top level dirs representing related projects in the aria's tale fantasy narrative universe:

1. legacy/ - this is the legacy public website repo
2. mcp/ - this contains an mcp server for local ai-assisted tabletop roleplay
3. rag/ - this contains a rag of aria's tale knowledge

each project has it's own README.md and copilot-instructions.txt for more context on conventions within that project subdirectory, such as how to set up, install, and use that project.
